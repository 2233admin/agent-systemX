# FTS5 BM25 Configuration Search Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在保留现有 SQLite 配置修订存储的前提下，增加隐私安全的 FTS5 全文检索，并提供 revision-level 的 BM25 排序 CLI 查询与重建能力。

**Architecture:** 新增 STRICT 普通投影表 `config_search_document`，以一行对应一个 `stable_config_revision`；新增 external-content FTS5 表 `config_revision_fts`，索引配置名、公开 scope boundary、capability names/summaries 与 `trigger_category`。写入投影和 FTS 维护放在 `establish`/`revise` 的同一 SQLite 事务中；`--rebuild` 从权威修订表重建投影和索引。应用层负责 NFKC、大小写归一化及 Han overlapping bigrams，查询只返回 revision-level 结果并按 BM25 相关性排序，不产生推荐。

**Tech Stack:** Bun/TypeScript、`bun:sqlite`、SQLite FTS5 `unicode61`、现有 `configs` CLI、`bun:test`。

**Spec:** 本任务中用户已批准的 FTS5/BM25 搜索设计（2026-08-27）。

## Global Constraints

- MUST 保留 SQLite 作为权威存储，并新增 STRICT `config_search_document` 普通投影表与 external-content `config_revision_fts`。
- MUST 仅索引 config name、known public scope boundary、capability names/summaries、`trigger_category`。
- MUST NOT 索引或持久化 prompt、transcript、secrets、private raw/sourceRef/evidenceRef/contentFingerprint/errors。
- FTS5 tokenizer MUST 使用 `unicode61`；应用层 MUST 做 NFKC、大小写归一化和 Han overlapping bigrams。
- CLI MUST 支持 `configs search <query> [--limit<=50] [--json]` 与 `configs search --rebuild`。
- 搜索结果 MUST 是 revision-level，相关性顺序 MUST 只由 BM25 决定，MUST NOT 输出 recommendation。
- `establish`/`revise` 更新 projection 与 FTS MUST 与修订写入处于同一事务。
- MUST 覆盖中文、英文、特殊字符、limit、rebuild、privacy 与 regression 测试。
- 本计划不提交、不修改上述文件清单之外的文件。
